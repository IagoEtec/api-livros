## Sobre o projeto

Este projeto foi desenvolvido para a disciplina de **Sistemas Web II (SW-II)**, com o objetivo de construir uma aplicação completa de gerenciamento de livros.

A aplicação integra **API, banco de dados e Front End**, permitindo cadastrar, consultar, atualizar e excluir livros através de uma interface web.

> **Projeto acadêmico · 3º Bimestre**

---

## O desafio

A proposta é desenvolver uma aplicação web utilizando **FastAPI**, conectada a um banco de dados **MySQL**, e posteriormente construir uma interface capaz de consumir a API.

Cada livro possui as seguintes informações:

| Campo            | Descrição                |
| :--------------- | :----------------------- |
| `id`             | Identificador único      |
| `titulo`         | Título do livro          |
| `autor`          | Autor do livro           |
| `ano_publicacao` | Ano de publicação        |
| `disponivel`     | Disponibilidade do livro |

---

## CRUD

A aplicação implementa as quatro operações fundamentais:

<div align="center">

|     |  Operação  | Função                    |
| :-: | :--------: | :------------------------ |
|     | **Create** | Cadastrar livros          |
|     |  **Read**  | Listar e consultar livros |
|     | **Update** | Atualizar livros          |
|     | **Delete** | Excluir livros            |

</div>

## Jornada do projeto

### Etapa 1 · Fundação

Configuração do ambiente, instalação das dependências, criação do banco de dados e conexão entre **FastAPI e MySQL**.

### Etapa 2 · Modelo e consultas

Criação do modelo `Livro`, schemas, sessão do banco e implementação das rotas `POST` e `GET`.

### Etapa 3 · CRUD completo

Implementação das rotas `PUT` e `DELETE`, validações e tratamento de erros.

### Etapa 4 · Front End

Construção da interface utilizando **HTML, CSS e JavaScript**, permitindo interagir com a API diretamente pelo navegador.

## Objetivos

Ao desenvolver o projeto, são trabalhados conceitos como:

* criação de APIs REST;
* utilização de `GET`, `POST`, `PUT` e `DELETE`;
* integração entre Python e MySQL;
* criação de modelos e schemas;
* validação de dados;
* tratamento de erros HTTP;
* desenvolvimento de interfaces web;
* consumo de APIs utilizando `fetch`;
* organização de projetos;
* utilização do Git e GitHub.
